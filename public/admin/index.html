Connect to GitHub

Changes you make here are saved as commits to the website's GitHub repository. The site rebuilds automatically about a minute later.

How do I create a token?
  1. On GitHub, open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it e.g. Pelagos admin, choose an expiration (90 days is a good balance).
  3. Repository access: “Only select repositories” → pick pelagos.
  4. Permissions → Repository: Contents Read and write, Pull requests Read and write, Issues Read and write (Metadata read-only is added automatically). Actions Read is optional, to show deploy status.
  5. Generate, copy the token and paste it above. It is stored only in this browser (localStorage). Use “Forget saved token” on shared computers.
